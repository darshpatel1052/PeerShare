# Self-hosted typefaces

PeerShare uses Manrope for interface text and Barlow Condensed Bold for display headings. Both assets are served locally, so the interface does not contact a third-party font service.

Downloaded on 13 October 2026 from the official Google Fonts repository:

- [Manrope variable font](https://github.com/google/fonts/tree/main/ofl/manrope), with its accompanying `manrope-OFL.txt`.
- [Barlow Condensed Bold](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), with its accompanying `barlow-condensed-OFL.txt`.

The bundled license files are authoritative. The original font binaries are retained without modification.
